# THE HANDY HUB - UI Style Guide

## Brand Overview
THE HANDY HUB is a modern, stylish e-commerce platform for everyday household items and general merchandise. The design reflects quality, simplicity, and a premium shopping experience.

---

## 1. Color Palette

### Primary Colors
- **Charcoal Grey:** `#333333` (Used for headers, text, and strong accents)
- **Vibrant Orange:** `#FF6B35` (Accent color for Call-to-Actions (CTAs), buttons, and highlights)

### Secondary & Backgrounds
- **Warm Neutral:** `#F7F3F0` (Main background for sections and cards)
- **Off-White:** `#FFFFFF` (Main page background)
- **Soft Border:** `#E5E5E5` (For dividers and input borders)

### Feedback Colors
- **Success:** `#4CAF50`
- **Error:** `#E63946`
- **Warning:** `#FFC107`

---

## 2. Typography

### Headings
- **Font Family:** `Montserrat`, sans-serif
- **Weight:** Semi-Bold (600) or Bold (700)
- **Usage:** Hero titles, section headers, product names.

### Body Text
- **Font Family:** `Inter` or `Open Sans`, sans-serif
- **Weight:** Regular (400)
- **Line Height:** 1.6
- **Usage:** Product descriptions, blog posts, general copy.

---

## 3. UI Components Style

### Buttons
- **Primary:** Background `#FF6B35`, Text `#FFFFFF`, Border-radius: `4px`
- **Secondary:** Background `transparent`, Border `2px solid #333333`, Text `#333333`
- **Hover State:** Slightly darken background colors on hover.

### Cards (Product Grid)
- **Background:** `#FFFFFF`
- **Shadow:** Light subtle shadow (`0px 4px 12px rgba(0, 0, 0, 0.05)`)
- **Border Radius:** `8px`
- **Padding:** `16px`

### Input Fields
- **Border:** `1px solid #E5E5E5`
- **Focus State:** `1px solid #FF6B35`
- **Border Radius:** `4px`

## 5. Design Principles
1. **White Space:** Use generous white space to allow products to breathe.
2. **High-Quality Imagery:** Always use sharp, well-lit product photography.
3. **Consistency:** Ensure buttons and spacing are consistent across all pages.
4. **Mobile First:** Ensure the layout is responsive and accessible on all devices.
